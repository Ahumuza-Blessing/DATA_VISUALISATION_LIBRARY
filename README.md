# DATA_VISUALISATION_LIBRARY# CPP Data Visualization Library

## 1. Project Description
A reusable C++ library for basic data visualization.

The library is intended to load data, process it, calculate simple statistics, and generate visualizations such as count plots, histograms, and KDE plots.

## 2. Project Objectives
- Apply C++ and Object-Oriented Programming concepts.
- Build a reusable C++ library.
- Load and process data.
- Generate basic statistical summaries.
- Create different types of plots.

## 3. Main Features
- Data loading
- Data preprocessing
- Statistical summaries
- Count plots
- Histograms
- KDE plots
- Axis scaling
- Labels and annotations
- Plot rendering
- Image export
